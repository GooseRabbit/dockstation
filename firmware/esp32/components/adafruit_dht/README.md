# Adafruit DHT Sensor Library

Upstream: https://github.com/adafruit/DHT-sensor-library
Pinned source release: 1.4.7
License: MIT (see license.txt).

This component builds the upstream DHT.cpp / DHT.h API against
Espressif Arduino Core for ESP32. The optional DHT_U wrapper is not included:
DockStation uses the basic DHT class and does not need Adafruit Unified Sensor.
