# Словарь терминов и сокращений

**Статус:** рабочий документ.  
**Редакция:** 0.1.

| Термин | Значение |
|---|---|
| БАС | Беспилотная авиационная система |
| БПЛА | Беспилотный летательный аппарат |
| Док-станция | Наземная станция приёма и обслуживания БАС |
| Автопилот | Бортовая система управления полётом |
| BMS | Система управления аккумуляторной батареей |
| BLE | Bluetooth Low Energy, технология Bluetooth с низким энергопотреблением |
| AprilTag | Система визуальных маркеров для обнаружения и оценки положения |
| UWB | Сверхширокополосная радиотехнология, потенциально применимая для измерения расстояния и позиционирования |
| MAVLink | Протокол обмена сообщениями, применяемый в некоторых системах автопилотов |
| RS-485 | Физический интерфейс последовательной связи |
| Modbus RTU | Протокол обмена данными, часто применяемый поверх последовательного интерфейса |
| TLS | Протокол защиты сетевого соединения |
| SHA-256 | Криптографическая хеш-функция |
| КПД | Отношение полезной выходной энергии/мощности к входной по определённой методике |
| Манифест файлов | Перечень файлов и их метаданных для передачи |
| Контрольная сумма | Значение для проверки целостности данных |
| Идемпотентность | Свойство, при котором повтор одного запроса не приводит к нежелательному повторному эффекту |
| Конечный автомат | Модель программы с ограниченным набором состояний и разрешённых переходов |
| Межблокировка | Условие, запрещающее операцию при небезопасном состоянии |
| Телеметрия | Данные о состоянии системы, передаваемые для наблюдения и анализа |
| Заглушка | Временная имитация функции, не являющаяся её реальной реализацией |
| Имитатор | Программный компонент, воспроизводящий поведение оборудования в тесте |
| SafetyManager | Логический модуль контроля безопасности станции |
| StationStateManager | Модуль управления состояниями станции |
| MissionManager | Модуль управления заданиями и миссиями |
| WeatherManager | Модуль обработки метеоданных |
| DetectionManager | Модуль обнаружения и идентификации БАС |
| LandingManager | Модуль управления данными посадочного позиционирования |
| ChargingManager | Модуль управления процессом зарядки |
| CleaningManager | Модуль управления самоочисткой |
| DataManager | Модуль координации получения и передачи материалов |
| TransferQueueManager | Модуль управления очередью передачи |
| LocalStorageManager | Модуль локального хранения |
| UploadManager | Модуль отправки данных на сервер |

## Правило

Технический термин при первом использовании в новом документе желательно сопровождать русским пояснением. Названия программных модулей можно оставлять на английском для единообразия в коде.
