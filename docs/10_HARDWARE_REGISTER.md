# Перечень аппаратных узлов док-станции

**Статус:** предварительный перечень.  
**Редакция:** 0.2.

## 1. Назначение

Документ перечисляет физические узлы, которые потребуются для реализации функций станции.

Это не спецификация закупки. Конкретные модели, количества, номиналы и производители не выбраны.

## 11. Правила выбора оборудования

Для каждого компонента фиксировать:

- производителя и модель;
- ссылку на официальную документацию;
- диапазон питания;
- потребляемый ток;
- интерфейс;
- температурный диапазон;
- степень защиты;
- габариты;
- массу;
- точность;
- ограничения эксплуатации;
- совместимость;
- статус выбора;
- результаты испытаний.

Не выбирать компоненты только по названию или рекламному описанию. Нужны технические документы и проверка совместимости.
